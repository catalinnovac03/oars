OARS is published as an experimental public project RFC at [catalinnovac03/oars](https://github.com/catalinnovac03/oars). The exact Core version is `0.4-draft`.

## Available project infrastructure

The repository contains the canonical RFC, schemas, examples, conformance fixtures, a Python harness, contribution guidance, issue/PR templates, and automated validation. TypeScript and ecosystem profiles remain scaffolds.

Security reporting instructions are in [SECURITY.md](../SECURITY.md). No trademark policy, formal standards-body affiliation, or production-support commitment is assigned.
