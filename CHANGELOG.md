# Changelog

OARS is experimental before 1.0. The exact Core version is `0.4-draft`.

## 0.4-draft — October 2026

- Publish RFC 0001 as the canonical project specification, retaining the supplied 0.4 semantics and complete example record.
- Provide an experimental reconstructed JSON Schema, binding/fixture schemas, and documented serialization choices.
- Add Claims Assistant, Microsoft-to-AWS migration, and retrospective-correction examples.
- Add valid and intentionally invalid records plus deterministic authority-resolution vectors.
- Provide an executable Python harness, TypeScript implementation guidance, and profile guidance.
- Add local and GitHub Actions validation, contribution guidance, and issue/pull-request templates.

Schema reconstruction and unsettled resolution conventions are documented in [design decisions](docs/DECISIONS.md). No new Core version, settled 1.0 contract, or complete SDK is claimed.
