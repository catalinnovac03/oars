# Changelog

OARS is experimental before 1.0. The exact Core version is `0.4-draft`.

## 0.4-draft — October 2026

- Rename the project to **Open Authority Record Standard**, retaining the OARS acronym and Core version.

- Publish RFC 0001 as the canonical project specification, with the 0.4 Core model and complete example record.
- Provide an experimental JSON Schema, binding/fixture schemas, and documented serialization choices.
- Add Claims Assistant, Microsoft-to-AWS migration, and retrospective-correction examples.
- Add valid and intentionally invalid records plus deterministic authority-resolution vectors.
- Provide an executable Python harness, TypeScript implementation guidance, and profile guidance.
- Add local and GitHub Actions validation, contribution guidance, and issue/pull-request templates.

Experimental serialization and unsettled resolution conventions are documented in [design decisions](docs/DECISIONS.md). No new Core version, settled 1.0 contract, or complete SDK is claimed.
